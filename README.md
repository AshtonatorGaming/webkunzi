# Inkunzi

A staffed nation RP table: painted map, pops instead of provinces, war day, tick day. Players submit; staff adjudicate.

This checkout is the Grok Build preview (TanStack Start). Canon Next.js lives at [AshtonatorGaming/inkunzi](https://github.com/AshtonatorGaming/inkunzi).

```
npm install
npm run dev
```

Staff live is god mode for mapping tests. March approaches a banner; Attack is an explicit order. ZOC blocks pathing *through* a disk, not the kiss. War day resolves Shock / Early / Late as named unit lines and an I2/I3 grade. Tick day runs food, tax, and manpower. Export a world JSON to keep a season.
