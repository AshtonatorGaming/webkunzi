# Inkunzi

A staffed nation RP table: painted map, pops instead of provinces, Friday wars, Saturday ticks. Players submit; staff adjudicate.

This checkout is the Grok Build preview (TanStack Start). Canon Next.js lives at [AshtonatorGaming/inkunzi](https://github.com/AshtonatorGaming/inkunzi).

```
npm install
npm run dev
```

Staff live is god mode for mapping tests. March a banner into an enemy zone of control to declare. Friday resolves Shock / Early / Late. Saturday runs food, tax, and manpower. Export a world JSON to keep a season.
